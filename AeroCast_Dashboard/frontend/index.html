How AeroCast Works

Forecasts are generated offline in Python and displayed here

  1. CPCB + ERA5 DatasetHourly pollutant and meteorological observations
  2. Feature EngineeringStation-wise lags, rolling statistics, calendar features
  3. 42 XGBoost Models7 pollutants x 6 horizons, pretrained regressors
  4. Pollutant ForecastsConcentrations from +1 h to +72 h
  5. AQI + Trend AnalysisCPCB sub-indices, dominant pollutant, trends

The dashboard only reads exported CSV files through the Node.js API. It does not load, run or train any model.
